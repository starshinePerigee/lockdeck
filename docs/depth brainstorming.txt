FUNDAMENTAL RULE: PIN EXECUTIONS ARE INDEPENDENT
results can effect other pins, but these are evaluated *after* all pins and effects fire.

NICE
- breather: draw two cards
- info: tests a random depth
- slippery: if you test / reveal this pin, advance one

JAM DEPTHS (jammed: picks break if a lock is moved)
- bind: locks this pin until another one is set (if no others, reset another one)
- jammed: jams this pin for a turn
- x: jams this pin until it breaks a pin, or end of turn.

ANNOYING
- reset: resets another pin, or this one
- hint/key: depth required to activate to unlock the pin; hint reveals it (maybe weird without clear
- x: a depth that resets the pin if you skip it without exhausting it
- minima: if you test this depth, it pulls you to it
- stall: discards cards (percent of deck)
- fumble: discards your hand

ANTI-SKIP
- stuck: if you move past this depth, you don't
- stuck 2: if you move past this depth, subtract one movement

ANTI-JAM
- jam: jam trap. If you are below this depth and jam, the jamming pick breaks
- x: if you jam this pin, another pin resets

ANTI-TEST/REVEAL
- test 1 (anti-broad): if you test this depth twice without passing it, it breaks the test pick. (scans as safe)
- test 2 (anti-narrow): if this is the only depth you test, it breaks the test pick
- bomb (anti-reveal): if this is revealed, next turn you have to advance past it or the revealer breaks (also plays interesting with move into it, and move/jam!)
- super anti-reveal: if revealed, breaks pick. tests as safe

REVEALED AT START
- test 3 (landmine): if this depth is tested or revealed, it breaks the pick. revealed at start
- spike: revealed from the start. breaks.
- anti-landmine: if this depth is skipped, it breaks the pick. revealed at start?
- trap: a depth that breaks if you skip or activate it, but has an earlier depth that diffuses it (starts revealed)

MOTHERFUCKERS
- surprise: break without warning
- x: break from your deck (unless it's empty)


SUPPORT ARCS IN LOCK GENERATOR


Initial pass:
safe:
x- breather (draw two random from your discard, or deck if it's empty)
d- hint (shows a safe, or tags everything dangerous)
d- slip (reveal and advance on test/reveal)
d- catch (unless this pin is exhausted, if you are below this depth and jam, the jamming pick breaks. does nothing if activated)
x- labyrinth (breaks if revealed via reveal)
interesting:
d- fumble (discards hand)
d- bomb (advance past or die)
d- twist (discard 1 from deck when tested; does not reveal)
danger:
x- surprise (break from deck without warning)
n/a:
x- spike (revealed break)
x- trap (breaks if tested / revealed, but revealed at start)
d- gate / gate key
