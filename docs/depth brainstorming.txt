- bind: locks this pin until another one is set (if no others, reset another one)
- reset: resets another pin, or this one
- hint/key: depth required to activate to unlock the pin
- jam: jam trap. If you are below this depth and jam, the jamming pick breaks
- test 1 (anti-broad): if you test this depth twice without passing it, it breaks the test pick. (scans as safe)
- test 2 (anti-narrow): if this is the only depth you test, it breaks the test pick
- test 3 (landmine): if this depth is tested or revealed, it breaks the pick. revealed at start
- bomb (anti-reveal): if this is revealed, next turn you have to advance past it or the revealer breaks (also plays interesting with move into it, and move/jam!)
- trap: a depth that breaks if you skip or activate it, but has an earlier depth that diffuses it (starts revealed)
- super anti-reveal: if revealed, breaks pick. tests as safe
- stuck: if this is tested or revealed, if you break a pick this turn this pick is also broken
- x: a depth that resets the pin if you skip it without crush
- x: a depth that breaks if you reveal it (without activating it)
- crush trap: reads as safe, if you try to crush it, it breaks the crush
- x: if you jam this pin, another pin resets
- minima: if you test this depth, it pulls you to it
- stuck: if you move past this depth, you don't
- fumble: discards cards (percent of deck)
- darkness: if you hit both, the lights go out
- slippery: if you skip / test / reveal this pin, advance one
- surprise: break without warning
