build "depth templates"

a depth template is a set of depths, level building instructions (with unique depth counts per number of pins), a net hazard, and a set of weights (early: 1-3 pins, mid: 4-5 pins, late: 5 pin extended)

draw depths based on weight until a hazard threshold is reached

place all the depths according to their rules (randomly pick a pin with enough depth, then apply - do not stack depths by default)

track which depths were placed successfully

weights: how many copies to put in the draw deck

for each set of stages:
- build a deck of hazards by picking weighted-randomly until you have x hazard rating and y total templates - this deck is what is presented in the strategy hub and pulldown reference
-- if x and y are too out of sync, you can reject and redraw the next one (once/twice)

for each lock:
- build pin out of PENDING depths
- draw random weighted from the limited deck
- check if you can place depths and if hazard with within bounds
-- if so: place and update hazard
--- placing will be smart and will try every pin in random order
-- if not: reject
--- if reject (twice/thrice): end
-- if hazard and depth saturation are adequate, break
- convert all PENDINGs to empties
